# 📖 About

Welcome to my **MERN Learning Journey** repository.

This repository documents my complete learning journey in **Full Stack Web Development (MERN Stack)**. Every concept I learn is organized into separate folders with examples, practice files, notes, mini tasks, and real-world projects.

Instead of learning technologies separately, I follow a practical approach by building and practicing concepts together. For example, while learning **CSS**, I also practice **HTML**, and while learning **JavaScript**, I continue using both **HTML** and **CSS**. This helps me strengthen my fundamentals while learning modern web development.
